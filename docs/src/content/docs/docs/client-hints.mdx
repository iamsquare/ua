---
title: Client Hints
description: Parse Sec-CH-UA headers
---

Pass `withClientHints: true` and HTTP headers (or a `Headers` instance) to fill in fields from Client Hints. TypeScript requires `headers` when the flag is set:

```ts
import { parseUA } from '@iamsquare/ua';

const result = parseUA(undefined, {
  withClientHints: true,
  headers: {
    'user-agent': request.headers['user-agent'],
    'sec-ch-ua': request.headers['sec-ch-ua'],
    'sec-ch-ua-platform': request.headers['sec-ch-ua-platform'],
    'sec-ch-ua-mobile': request.headers['sec-ch-ua-mobile'],
    'sec-ch-ua-model': request.headers['sec-ch-ua-model'],
    'sec-ch-ua-arch': request.headers['sec-ch-ua-arch'],
    'sec-ch-ua-full-version-list': request.headers['sec-ch-ua-full-version-list'],
  },
});
```

When present, hints are merged into browser, OS, device, CPU, and engine fields.
