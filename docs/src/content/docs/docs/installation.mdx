---
title: Installation
description: Install @iamsquare/ua
---

```
pnpm add @iamsquare/ua
```

```
npm install @iamsquare/ua
```

```
yarn add @iamsquare/ua
```

ESM is the default entry. CommonJS works through `require()` when you need it.

```ts
import { parseUA } from '@iamsquare/ua';
```

```js
const { parseUA } = require('@iamsquare/ua');
```

Requires **Node.js 20+**.
