How `@iamsquare/ua` compares to other User-Agent parsers on this repo's fixture suite.

## How to read this

- **Accuracy** is string equality against fixture `expect` fields. Those expects are written for `@iamsquare/ua`, so other libraries can score lower on naming differences even when they are mostly right.
- **Speed** is mean throughput from [tinybench](https://github.com/tinylibs/tinybench) (sync single-UA parses over the fixture UA list), each library in its own Node process.
- **Size** is an esbuild bundle of each package entry (raw and gzip).

Refresh the snapshot locally (not in CI):

```
pnpm build
pnpm --dir benchmarks bench
```

That updates `docs/src/data/competitors.json`.

Libraries compared: [`ua-parser-js`](https://github.com/faisalman/ua-parser-js), [`my-ua-parser`](https://github.com/mcollina/my-ua-parser), [`bowser`](https://github.com/bowser-js/bowser), [`platform`](https://github.com/bestiejs/platform.js), [`detect-browser`](https://github.com/DamonOehlman/detect-browser).
